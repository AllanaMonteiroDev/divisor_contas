# divisor-conta

Segundo projeto da minha trilha de estudos em Python. Um programa simples que divide o valor de uma conta entre um grupo de pessoas e checa se dá pra pagar com o saldo que eu tenho.

Ainda tô no começo (variáveis, tipos, operadores, condicionais), então o código é bem simples de propósito o objetivo aqui é fixar conceito.
## O que o programa faz

Pede o valor total da conta e quantas pessoas vão dividir, calcula quanto cada um paga, e depois pergunta o saldo disponível pra ver se dá pra pagar (considerando também um teto de R$100 por pessoa).

## Conceitos que usei aqui

- input() com conversão pra float e int
- divisão e formatação de casas decimais
- comparação (>=, <=)
- and

## Sobre a trilha

Tô estudando Python do zero e, a cada conceito novo, faço uma leva de exercícios e um projeto pequeno pra fixar — mesmo que o projeto seja bem simples. Esse é o do módulo de operadores.
